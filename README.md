# 下载 Markeen Alpha

Markeen 用来阅读本机 Markdown 和 HTML，也可以在文档更新后核对修改前后的原句。项目文件留在原来的位置。

1. [打开下载页](https://github.com/lengqian/Markeen-releases/releases)，在顶部版本的 **Assets** 中下载 `Markeen-…-build….zip`。需要核对下载时，同一版本提供 `SHA256SUMS`。
2. 解压 ZIP，将 Markeen 拖到「应用程序」并打开。安装包以 macOS 12 或更新版本为目标，包含 Intel 和 Apple Silicon 两种架构。目前的实机验证来自 Intel Mac。
3. 点「打开文件或文件夹…」，直接读自己的文档。也可以点「用示例查看改动」，先看一次修改前后的文字。阅读时按 ⌘F 查找当前篇，按 ⌘K 搜索项目或同一文件夹。

当前 Alpha 尚未取得 Developer ID 发行签名和 Apple 公证，macOS 可能阻止首次打开。遇到提醒，请先核对下载来源和提示内容。 [Apple 安全打开 App 指南](https://support.apple.com/zh-cn/102445)

已经安装 Alpha 的读者可以从「Markeen → 检查更新…」更新。
